Cinemex API

API intermedia para consultar películas de TMDB. Documentación del proyecto Cinemex.
Contacto: equipo Cinemex
Versión: 1.0.0
BasePath: /api/peliculas
Servidor de producción:
https://cinemex-api-bye8gdg4chbsa7e3.northcentralus-01.azurewebsites.net/api/peliculas
Las rutas que no dependen de TMDB (/health, /docs, /openapi.json, /swagger) responden sin necesidad de credenciales. Las rutas de películas requieren que TMDB_API_KEY o TMDB_BEARER_TOKEN estén configuradas en el entorno.

Access

API pública, sin autenticación. El token de TMDB se gestiona internamente en el servidor y no se expone.
